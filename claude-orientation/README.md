# Claude Orientation

You installed Claude Code and don't know what to build. This tells you the one thing to build first and what to do tonight.

Beginners don't fail from lack of ideas. They fail from having five and finishing none. This skill places you on a 9-stage arc — install, memory, website, landing page, skills, game, agents, content, distribution — then **cuts your list down to one build** and writes tonight's single next move to a file you reopen every session.

## Install

1. Copy the `claude-orientation` folder into your Claude Code skills directory:
   ```bash
   cp -r claude-orientation ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/claude-orientation`.

## How to use

No setup needed. Type `/claude-orientation` and answer two questions: which stages you've actually finished, and every project you're currently thinking about. It picks your stage, cuts your project list to one, shrinks that one until it can ship in five nights, and parks the rest so nothing feels lost.

You get `~/claude-roadmap.md` with your stage, your one build, five nights of one-line moves, a 30-day arc, and the exact words to paste into Claude tonight. Open that file at the start of every session and rewrite the next-move line before you close the laptop.
