# Dissect

Paste a post that's performing and get back why it works — the hook, the structure, the format, the engagement driver — plus a brief for building your own version.

Copying a viral post gets you nothing, because the topic isn't what made it work. **The mechanism is what transfers.** This skill separates the two: it names the machinery underneath so you can run it on your own topic, for your own audience.

## Install

1. Copy the `dissect` folder into your Claude Code skills directory:
   ```bash
   cp -r dissect ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/dissect`.

## How to use

No setup needed. Nothing to configure, no profile to fill in first.

Paste a LinkedIn post, a Reel caption, a YouTube hook, or a Reddit thread — paste the text itself, not a link. You get six sections back: hook mechanism, structure pattern, format, engagement driver, three things worth stealing, and a recreation brief with the first line of your version already written.
