# Positioning Filter

Lock the one angle that makes you sound like you instead of everyone else in your niche.

Most offers don't fail because they're bad. They fail because nobody can tell them apart. This skill runs three questions and a cut test to force a single, defensible angle. The cut test is the part people skip: **you are defined as much by what you refuse to be** as by what you claim.

## Install

1. Copy the `positioning-filter` folder into your Claude Code skills directory:
   ```bash
   cp -r positioning-filter ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/positioning-filter`.

## How to use

Type `/positioning-filter`. It reads your brand profile at `~/.claude/brand-profile.md`, so run `/personalize` first if you haven't. It asks what you say that your niche doesn't, why your audience would care, and how that angle points at what you sell. Then it makes you cut: who this is not for, what topics you won't cover, what hedges to drop.

You get a positioning statement and a one-line differentiator saved to `~/offers/positioning.md`. Paste the one-liner into your bio and reuse the statement on any sales page.
