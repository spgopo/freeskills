# Learn Anything

Teaches you a topic at your actual level, and gives you three things to practise instead of a wall of text.

Most explanations miss because they're pitched wrong or they end with nothing to do. This one finds your real starting point, shows you **the shape of the thing before the details**, gives you the five ideas that carry most of it, and then hands you a ladder: fifteen minutes, an hour, one evening.

## Install

1. Copy the `learn-anything` folder into your Claude Code skills directory:
   ```bash
   cp -r learn-anything ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/learn-anything`.

## How to use

No setup needed. Type `/learn-anything` and name the topic — "teach me DNS", "explain how invoicing works", "I need to understand this by Monday".

It asks what you already know, why you're learning it, and how deep you need to go. Then it teaches in short passes with a real check question in the middle, not one long lecture. You finish with three exercises you can actually start tonight and the one wrong belief beginners in that topic usually carry around for months. Saved to `~/learning/`.
