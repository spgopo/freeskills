# Repeatable Offer

Turn the service you keep doing custom into one fixed thing you can sell over and over.

Custom work is exhausting because every sale starts at zero. You re-explain what you do, guess at a price, and then the job grows past what you agreed to. This skill finds **the part of the work that's the same on every job**, puts a box around it, and gives that box a name, a price, a timeline, and a checklist you follow every time.

## Install

1. Copy the `repeatable-offer` folder into your Claude Code skills directory:
   ```bash
   cp -r repeatable-offer ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/repeatable-offer`.

## How to use

Run `/personalize` once first so it knows your niche, offer, and audience. Then type `/repeatable-offer`.

It walks you through the last few jobs you did and finds what repeated, then makes you turn that into one deliverable with a real finish line. The hard part is step 4, where you write down what is NOT included, because that's the thing that keeps the job from quietly growing. You end with a name, a one-line promise, a fixed price, and the delivery checklist you run on every order.

You get a one-page offer saved to `~/offers/<product-name>.md`. It works as the page you send a buyer and as the checklist you follow while you deliver.
