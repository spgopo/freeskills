# Case Study

Turn one win into a short write-up you can send to a prospect or post publicly.

A finished project sitting in a folder does nothing for you. This skill turns it into a page built on a real before and after: where they started and what it was costing them, what you built, what changed, and **one honest line about the hard part** — which is the section people cut, and the one that makes the rest believable.

## Install

1. Copy the `case-study` folder into your Claude Code skills directory:
   ```bash
   cp -r case-study ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/case-study`.

## How to use

Run `/personalize` once first. Then type `/case-study` and say what you built and who for — a paid client, a free favour, or your own project all work the same way.

It interviews you properly, pushing for the specifics most people leave out, and it will not invent a metric. If there's no number it uses a concrete before/after description instead, which reads just as well. You get two versions — a tight one for a DM and a longer one for LinkedIn or a portfolio — saved to `~/case-studies/`.
