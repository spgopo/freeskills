# Free Skills

50 free Claude Code skills for beginners.

Each skill lives in its own folder. Grab the one you want, drop it into your Claude Code skills directory, and start using it. That's the whole setup.

No API keys. No installs. No scripts to run. If you have Claude Code, these work.

## Is this the right repo for you?

**Yes, if you're new.** Everything here runs the moment you drop the folder in. No API keys, no installs, no accounts to wire up. These skills teach you Claude Code, get your first things built and live, and help you tell people about them.

**You'll want [profit-room-skills](https://github.com/duncan-buildroom/profit-room-skills) once you're past that.** That's the heavier set — full content pipelines, video and thumbnail generation, carousel rendering, publishing automations, site builders. Those skills do more, but they need API keys, connected tools, and a bit of setup. Start here, go there when the simple version stops being enough.

Some skills appear in both. Same skill, no catch.

## Start here

Run [`personalize`](./personalize) first. It asks you a few questions about your name, niche, offer, and audience, then saves the answers to `~/.claude/brand-profile.md`.

A lot of these skills read that file. That's how they write in your voice, for your audience, without you re-explaining yourself every time. You only do this once.

Then run [`claude-orientation`](./claude-orientation) to pick your first build and write down tonight's next move.

## A suggested order

If you want a path instead of a menu:

**Week 1 — get set up and ship something**

1. `/personalize` — set up your profile
2. `/claude-orientation` — pick ONE build
3. `/safety-net` — learn the two undo buttons so you stop being careful
4. `/first-website` or `/simple-game` — build the thing
5. `/deploy-it` — get it on a real URL and send it to one person

**Week 2 — make it good and tell people**

6. `/design-taste` — write down a look that's yours
7. `/make-it-designed` and `/mobile-check` — polish it
8. `/caption-writer` — post about it

**Week 3 — turn it into money**

9. `/offer-builder` — build something worth selling
10. `/pricing-calculator` — put a real number on it
11. `/warm-outreach` then `/dm-writer` — find the first people to tell
12. `/first-customer-closer` and `/objection-handler` — have the conversation

Then `/session-wrapup` at the end of each night and `/weekly-review` on Sundays, so none of it gets lost.

## How to install a skill

A skill is just a folder with a `SKILL.md` inside. To install one:

1. Download the folder for the skill you want (see [Downloading a single folder](#downloading-a-single-folder) below).
2. Move it into your Claude Code skills directory:
   - **Personal (all projects):** `~/.claude/skills/`
   - **Project-only:** `.claude/skills/` inside the project
3. Restart Claude Code (or start a new session).
4. The skill is now live. Invoke it by typing `/` followed by the skill name, for example `/personalize`.

Your folder should end up looking like this:

```
~/.claude/skills/
└── personalize/
    └── SKILL.md
```

## Downloading a single folder

You don't have to clone the whole repo. A few easy ways to grab just one folder:

**Option A — clone once, copy what you want**

```bash
git clone https://github.com/duncan-buildroom/freeskills.git
cp -r freeskills/personalize ~/.claude/skills/
```

**Option B — install all 50 at once**

```bash
git clone https://github.com/duncan-buildroom/freeskills.git
cd freeskills
for d in */; do cp -r "$d" ~/.claude/skills/; done
```

**Option C — download the whole repo as a ZIP**

Click the green **Code** button on the [repo page](https://github.com/duncan-buildroom/freeskills), choose **Download ZIP**, unzip it, and copy the folder you want into `~/.claude/skills/`.
