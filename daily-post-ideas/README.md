# Daily LinkedIn Post Ideas

Five LinkedIn post ideas for today, each with a hook line you can paste straight in and one line on where the post goes.

The five ideas are never five versions of the same thing. Each one comes from a different category — Lesson, Hot Take, Story, Tool Tip, Community Pull — so you're covering different reasons someone stops scrolling. **The hooks use your audience's own words**, pulled from your profile, not marketing-speak.

## Install

1. Copy the `daily-post-ideas` folder into your Claude Code skills directory:
   ```bash
   cp -r daily-post-ideas ~/.claude/skills/
   ```
2. Restart Claude Code (or start a new session).
3. Invoke it by typing `/daily-post-ideas`.

## How to use

It reads your brand profile at `~/.claude/brand-profile.md`, so run `/personalize` first if you haven't. That's where your audience, offer, proof, and tone come from.

Type `/daily-post-ideas`. No topic needed, no web search, no other input. You get five numbered ideas back. Pick one and say "write it" to get the full post drafted.
